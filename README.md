# Kauppaan

A shopping list app built with Next.js, React, and TypeScript.
Add products, mark them as purchased, filter the list, or remove completed items.

Shopping list data is stored in the browser with IndexedDB and stays on the
current device and browser. No account or server-side database is required.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
npm run prettier
```
